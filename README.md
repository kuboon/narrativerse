# Narrativerse

みんなで広げる、物語の世界。

## コンセプト
Narrativerse は、他の人が書いた物語を途中から分岐して別の話を書いたり、登場人物や小道具を共有して物語を作ったりできる、物語のためのソーシャルプラットフォームです。

### 要素
キャラクター、小道具、場面などの要素をあらかじめ作成、または既にあるストックから選択し、関連付けることができます。
物語の中でのそれらの要素の役割をあらかじめ書いておくことで、 AI が物語を書くヒントを提案してくれます。

### プロット
要素が決まったら物語を書いていきましょう！
あらかじめ用意された要素をベースに AI がアイデアを提案してくれます。

プロットは複数のシーンで構成されます。
シーンを1つ書き上げると、それをベースに AI が次のシーンのアイデアを提案してくれます。

## 分岐
物語を読んでいる最中に別の展開を考えついたら、そこから分岐してあなたの新しい物語を書いてみましょう。新たに要素を追加するのも、役割を変えてしま変えてしまうのも自由です。
